# Template status

The copied app, Supabase schema, migration history, and local unit tests are
present in this folder. The frontend is intentionally disconnected until a new
Supabase project is configured.

Before using this template:

- Configure a new backend and confirm its project reference.
- Add your organization name, logo, and contact details.
- Review role assignments, workflow stages, and printing-area names.
- Customize and review the privacy and terms pages.
- Run the tests and verify each role using disposable test accounts.

No source-project credentials, production database link, backups, or session
logs belong in this template.
